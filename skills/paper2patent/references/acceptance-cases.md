# 验收案例与边界

运行scripts/test_tools.py验证引用解析、碰撞、端口、标签及输入错误，再运行scripts/test_acceptance.py验证来源、正文、权项、图规范及实际SVG的集成。测试使用Python标准库；PNG预览另用可选CairoSVG。

公开的tests/fixtures/只保存重新编写的合成传感器窗口处理案例，包括技术披露、五部分草稿、图规范、证据表和来源记录。此案例不是已发表论文、真实实验或专利申请；所有参数都是显式配置，不代表测量结果。材料遵循本skill的MIT许可证，可公开再分发。

| 场景 | 验收行为 |
| --- | --- |
| 合成技术披露的集成交付 | 三项权利要求、窗口均值公式、来源定位、七步与循环附图进入语义复核 |
| 缺少方法材料 | 记录missing及缺口，保持draft状态 |
| 只有已有草稿 | 完整转换不能把草稿当原始技术证据；可执行内部一致性工作 |
| 只检查权项 | 不要求论文或完整证据表 |
| 只生成附图 | 可依据现有说明书，说明未进行论文回溯 |
| 错误记录 | 重复或不存在的ID、错误引文位置、图边错误、缺少覆盖、术语标号冲突需报错 |
| 缺少正文或图输入 | 报告未执行的检查，缺口不能呈现为已验证 |
| 错误来源哈希或过期SVG | 完整性或交付检查失败，保持draft状态 |
| 外部SVG | 报告需要视觉复核，不声称已验证其全部技术关系 |

测试在临时目录生成输出。来源定位使用合成披露的实际行号，SHA256由文件内容计算；来源记录同时声明材料性质与许可证。测试fixture是机械检查的已知输入，不是模型根据论文自主生成的输出。

## 生成质量评估

脚本测试不能证明任意论文的转换质量，也不替代技术支持、充分公开、引用基础或保护范围的人工审查。公开版本不附带用户论文、专利草稿或本机会话试用记录，也不把这些记录当作公开基准。

后续生成质量评估可使用允许公开的不同领域论文、仅摘要输入及已有草稿三个任务。保留原始任务、材料许可和实际输出，按实际环境记录是否独立会话；核查特征遗漏、参数编造、必要公式、引用基础及附图关系。未运行的任务明确记为未运行，准备好的fixture不计为模型生成结果。
