# 输入评估

## 按模式检查材料

完整转换至少需要标题、摘要和完整核心方法，优先使用全文、补充材料和原图。仅有摘要时产出贡献摘要与缺口，不生成看似充分公开的完整专利。

草稿修订需要现有文本和范围；只有草稿时核对格式与内部一致性，技术来源标为待核验。权项检查只要求权项，缺少论文或说明书不阻止机械检查。仅附图需要已有权项、说明书和附图说明，论文可选。导出 prompt 不检查论文输入。

## 接收文件

从已提供材料读取信息，避免要求用户重复粘贴。为来源分配稳定 ID，保存版本、章节、页码、图号或公式号。PDF 核对双栏顺序和符号，扫描件回看关键 OCR 结果；不可读取的页面记录为缺口。

记录材料清单、核心方法、修改目标、已有申请或草稿及交付格式。缺失的参数、结构或场景不靠猜测补写。

## 申请条件与可专利性

用户请求申请适用性或可专利性判断时，使用上下文中的公开时间与渠道、拟申请或优先权日期、已有申请和对比文件；实质信息缺失再询问。按 [legal-basis.md](legal-basis.md) 核对条件。

区分论文声称创新、检索得到的区别与法律判断。按请求检索现有技术并保存来源与日期；仅起草不自动扩成全面检索。未检索时标记新颖性和创造性未评估，继续生成有依据的技术草稿。

AI / 算法方案核对技术输入输出、具体技术关系、必要结构、训练或推理步骤及效果来源。仅有抽象目标时记录实现缺口。

## 完成条件

来源可定位，范围符合模式，方法和效果具备依据，缺口已限制输出。事实记录按 [evidence-mapping.md](evidence-mapping.md) 保存。
